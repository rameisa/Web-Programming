# Web Application Development

A collection of projects and practice work from my Web Application Development course, showing the fundamentals of building for the web.

## 📚 What's Inside

- **Basic HTML Tags Lecture**: examples of core HTML elements and page structure
- **Portfolio Project**: a personal portfolio website built with HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rameisa/Web-Application-Development.git
   ```
2. Go into the project folder:
   ```bash
   cd Web-Application-Development
   ```
3. Open `index.html` in your browser (or use the Live Server extension in VS Code).
